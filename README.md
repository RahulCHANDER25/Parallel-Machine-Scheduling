# Parallel-Machine-Scheduling
Benchmarking of multiple algorithms for a real-world semiconductor workshop scheduling

## Best Algorithm

Our best algorithm is `Minizinc`, you can find the actual code in `minizinc/` folder.
The instruction to run the **minizinc** code is in `minzinc/minizinc.ipynb` notebook file.
